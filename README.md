# Pinned compatibility inventory

Generated source discovery, not execution or complete runtime enumeration. Source cases keep their source paths, identities, commit pins and line numbers. Macro/parameter expansion and some test kinds are not covered. Unreadable source files and missing LFS fixture payloads are explicitly listed.

`ports/` separately records written Rust ports; `not_ported` in a raw discovery report is its initial classification, not the merged port ledger. Execution evidence belongs to the corresponding CI run, not this source scan.

Do not calculate a full Blender compatibility percentage from these source counts.
