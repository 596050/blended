# Blended

Browser-based 3D studio and test-driven Blender compatibility project.

Status: bootstrapping. Full Blender and Cycles parity has not been implemented or verified. This is an independent project, not an official Blender release.

The initial studio builds from a pinned Solarxy Rust/WebGPU source revision. Blender and Cycles are pinned reference implementations. Every compatibility case must retain upstream provenance; written, executed, failing and unsupported tests are reported separately. Native, WebAssembly and deployed-browser results must not be conflated.

The deployment target is GitHub Pages using standard free GitHub Actions runners for this public repository. No paid service is authorised.
